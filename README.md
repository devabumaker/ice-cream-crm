# Ice Cream CRM

> Управление продажами, клиентами и доставкой для дистрибьютора мороженого.

Ice Cream CRM — локальная CRM-система для ежедневной работы команды: от каталога и остатков до заказов, маршрутов и аналитики.

## Возможности

- **Дашборд** — KPI, последние заказы и товары с низким остатком
- **Клиенты** — магазины, кафе, киоски и рестораны
- **Каталог** — SKU, цены, остатки и партии
- **Склад** — приходы, списания и контроль остатков
- **Заказы** — создание заказов и автоматическое списание со склада
- **Доставки и маршруты** — планирование визитов торговых представителей
- **Финансы и отчёты** — продажи, оплаты и сводная аналитика
- **Команда и аудит** — роли пользователей и история действий
- **Клиентский портал** — просмотр и оформление заказов клиентом

## Технологии

- Next.js 15 + React 19
- TypeScript
- Tailwind CSS 4
- SQLite + better-sqlite3
- Drizzle ORM
- Lucide React

## Быстрый старт

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Для production-сборки:

```bash
npm run build
npm start
```

## Docker

```bash
docker compose up --build
```

Локальная база создаётся автоматически в `data/` и намеренно не попадает в Git.

## Структура

```text
src/app/          страницы и API-маршруты
src/components/   переиспользуемые UI-компоненты
src/lib/           база данных, авторизация и бизнес-логика
data/              локальные данные SQLite (не коммитятся)
```

## Безопасность

Перед первым использованием создайте администратора через экран входа. Не храните реальные пароли, токены или `.env`-файлы в репозитории.
